## 一、我理解的需求

1. 你在 ComfyUI 里用「外补画板（可视化）」节点拖边框扩图，再把结果喂给「Qwen Image 2.1 扩图」工作流生成，效果很好。
2. 你希望智能画布里图片节点顶部菜单的**"扩图"**也变成同样的体验：编辑器操作方式对齐外补画板，点"运行"时**调用本机 ComfyUI 里的那条扩图工作流**来出图。
3. 参考标准是 `E:\ComfyUI_Models\workflows\Qwen Image 2.1 扩图.json` 在 ComfyUI 里的实际用法；要配合的工作流是项目里已有的 `workflows/system/Qwen Image 2.1 扩图_无限画布专用api.json`。
4. **扩图编辑器只有一套交互**（新外补画板式），在线模型和本机 ComfyUI 两条生成路径共用它，差别只在运行时的参数可见性/锁定与提示词组装。

## 二、截图节点在干什么（分析结论）

### 后端逻辑（`外补画板（可视化）.py`，159 行）

| 控件 | 作用 |
| --- | --- |
| 单位 | 左/右/上/下的数值按**像素**还是**百分比**解释 |
| 左/右/上/下 | 四边各向外扩多少 |
| 最大输出长边 | 扩完的画布长边超过这个值就整体等比缩小（防止图太大） |
| 整除数 | 输出尺寸凑成 8/16/32/64 的整数倍（AI 模型要求），只微调有外补的那几条边，**绝不裁到原图** |
| 外补颜色 | 扩出来的条带填什么颜色，默认灰色 #808080 |
| 自由比例 | 选 1:1、9:16、16:9 等 11 种比例后，四边扩多少由比例自动算 |

它输出三样东西：
1. **扩好的大画布图**（原图贴在灰色底上）；
2. **遮罩**（白色 = 灰条带 = 需要 AI 生成的区域，原图区域是黑的）；
3. **外补是否存在**（四边都是 0 就是 False，不用生成）。

### 前端交互（`goohai_outpaint_visual.js`，923 行）

- **拖四边/四角**向外扩；拖动很跟手（条带宽时点中间直接跳到该位置）。
- **拖动原图**在画布里重新定位（输出框大小不变，四边此消彼长）。
- **按住 Shift** 变成对称扩展（拖一边，对面同步扩）。
- **滚轮缩放、中键平移**看大图。
- **数值框 ↔ 拖拽双向同步**：拖了框，数字跟着变；改数字，框跟着变。
- **比例下拉与拖拽联动**：选了比例后拖一边，其他边自动按比例补齐。
- 画面上实时显示**最终输出尺寸**和**四边的数值标注**，青色线框是输出边界。
- "加载"按钮是 ComfyUI 特有的（先跑上游节点拿预览），画布场景里图片本来就在手上，**这个不需要迁移**。

## 三、扩图工作流是怎么运作的（分析结论）

`Qwen Image 2.1 扩图_无限画布专用api.json` 的链路（已通读）：

```text
加载图像(RGBA，透明通道=遮罩)
 → 孤海遮罩分析（找白色区域的范围）
 → 数学运算（算横/纵扩展系数）
 → GH_MaskCropV2（按遮罩裁出一块"原图+待扩区域"的小图）
 → 图像缩放V2（长边缩到 1024~最大采样尺寸 之间，凑 32 整除）
 → 文字编码（固定指令"移除图像中的灰色区域，无缝自然延展为完整图像" + 补充提示词）
 → Qwen 2.1 Turbo + 扩图 LoRA（强度 0.7）采样生成
 → GH_CropRestore（把生成结果羽化贴回原尺寸大画布）
 → SaveImage
```

四个关键认知：

1. **工作流自己负责"裁→生成→贴回"**，画布端只需要把"带灰条带的大画布图 + 白色遮罩"做成一张 RGBA 大图交给它。
2. **灰色是 LoRA 训练约定**，固定提示词里写死了"灰色"——所以 ComfyUI 模式底色必须锁灰（批注 2）。
3. **遮罩传递方式画布已经支持**：画布现有的 ComfyUI 通道会自动把"白色遮罩"合成为透明通道再上传（`comfyNameForMaskedRef`），和这条工作流的入口约定完全吻合，不用新发明机制。
4. **#27「最大采样尺寸（长边）」**（孤海万能滑条，工作流里值=2048）：真正生效的只有数值 `值`，滑条视觉范围是 ComfyUI 前端属性、不随 API 提交。它的语义是 `实际采样长边 = min(max(1024, 裁图长边), 该值)`——越大越清晰、越吃显存。这个参数要映射进扩图编辑器（批注 6）。

## 四、画布现有"扩图"是什么状况

- 现在的扩图是**纯前端功能**：拖框 → 选底色 → 拼一张大图 → 发给**在线模型**（API 平台的扩图能力）生成。服务端 `main.py` 里没有任何扩图逻辑，**完全没接 ComfyUI**。
- 画布已有一条通用的"本机 ComfyUI 工作流"执行通道（引擎切到 ComfyUI 时：选工作流 → 按配置映射参数 → 提交后台任务 → 轮询取图），**包含用量记账、断线恢复、任务持久化**，修图/高清放大/多角度等功能都走它。
- 缺口只有两个：扩图工作流**缺参数映射配置文件**（`.config.json`）；扩图运行逻辑**缺 ComfyUI 分支**。

## 五、改造方案（已按批注定稿）

### A. 扩图编辑器交互升级（唯一一套，两条路径共用）

替换现有 outpaint 弹窗交互，对齐外补画板：

- 单位（像素 / 百分比）
- 左 / 右 / 上 / 下 数值输入（带 − / + 按钮），与拖拽双向同步
- 比例下拉（自由 + 11 种常用比例，选比例自动补齐四边）
- 最大输出长边
- 整除数（0 / 8 / 16 / 32 / 64）
- Shift 对称拖拽、复位按钮保留
- 画布上实时显示最终输出尺寸 + 四边数值标注（照搬外补画板画法）
- 几何算法移植 `_output_geometry`：预览尺寸 = 实际输出尺寸
- **补充提示词输入框**（新增，带说明文字）：
  - 说明示例：`可选。想额外告诉 AI 扩出来的部分该有什么内容/延续什么氛围时再填，例如"延续沙滩与海浪，右侧补一只海鸥"。留空则只做无缝延展。`
- **底色选择**：保留 6 色按钮（白/红/绿/蓝/灰/黑）——**在线模型模式可选**；**引擎=本机 ComfyUI 时整排置灰禁用、强制 #808080 灰**，并给一行提示"ComfyUI 扩图模型按灰色训练，底色已锁定"。
- **最大采样尺寸（长边）**（新增，仅 ComfyUI 模式显示）：数字输入 + 滑条，范围 1024–4096、步长 128、默认 2048，直接写入工作流节点 #27 的 `值`；旁边一行说明"越大越清晰、越慢越吃显存"。

### B. 运行链路（按引擎分流，编辑器不分流）

`runImageOutpaint()` 改造：

- **共同部分**：读取新编辑器的四边扩量/比例/最大输出长边/整除数 → 按移植的几何算法算出最终画布 → 合成大图上传 → 创建"扩图生成"输出节点（保留 `outpaintFrame` 追溯字段）。
- **引擎 = 本机 ComfyUI**：输出节点固定走扩图工作流，参数：补充提示词→节点 51、最大采样尺寸→节点 27、种子随机；**张数固定 1**（张数控件置灰显示"ComfyUI 模式一次 1 张"）；提示词 = 节点 53 固定指令（灰）+ 节点 51 补充提示词，由工作流自己拼接。
- **引擎 = 在线模型**：沿用现有在线调用，但**提示词逻辑统一改为**：`"移除图像中的{颜色名}区域，无缝自然延展为完整图像。"` + 补充提示词拼接（替换现在那句"在×色区域自然延展原有场景…"的旧模板）；张数/分辨率/模型选择等控件维持现状。
- 四边扩量全为 0（= "外补是否存在"False）→ 运行按钮置灰，提示"未扩图，无需生成"。

### C. 新建参数映射配置

新建 `workflows/system/Qwen Image 2.1 扩图_无限画布专用api.config.json`：

| 字段 | 对应工作流节点 | 编辑器来源 |
| --- | --- | --- |
| 源图像 | 56 加载图像 | 自动合成的大图 |
| 补充提示词 | 51 | 编辑器输入框 |
| 固定指令 | 53（默认"移除图像中的灰色区域…"） | 不暴露，保持默认 |
| 随机种子 | 18 | 每次随机 |
| 最大采样尺寸 | 27（默认 2048） | 编辑器滑条 |
| LoRA 强度 | 17（默认 0.7） | 不暴露，保持默认 |

有了它，普通工作流选择器里也能直接跑这条扩图工作流；扩图编辑器的 ComfyUI 分支也共用这份配置。

## 六、已确认的决定（原 5 问 + 新增映射）

1. **在线模型扩图路径保留**；但扩图**交互只留一套新的**，新编辑器同时服务两条路径（批注 1）。
2. **底色**：在线模式自选颜色；**ComfyUI 模式禁用选色、锁死 #808080 灰**（批注 2）。
3. **张数**：ComfyUI 模式**固定 1 张**，控件置灰说明；在线模式不变（批注 3）。
4. **补充提示词进编辑器**，带说明文字；**两条路径统一提示词逻辑** =「移除图像中的{颜色名}区域，无缝自然延展为完整图像。」+ 补充提示词，在线模式按自选颜色替换"灰色"二字（批注 4）。
5. **环境已确认**：本机 ComfyUI 装有 Goohaitools 插件与 Qwen 2.1 扩图模型，配置组已绑定本机 ComfyUI（批注 5）。
6. **新增**：工作流节点 #27「最大采样尺寸（长边）」映射为编辑器滑条+数字输入（1024–4096，步长 128，默认 2048），仅 ComfyUI 模式显示（批注 6 / 截图）。
