# 协作抽屉模式切换按钮可见性设计

## 目标

修复智能画布协作成员抽屉右上角“治理模式 / 普通模式”切换按钮在深色主题中出现浅色文字与浅色背景叠加、文字不可辨识的问题。

## 范围与方案

仅调整 `static/css/smart-canvas.css` 中 `[data-switch-mode]` 的展示样式：为按钮提供独立的深色/品牌色底色、高对比前景色、可辨识边框，以及悬停和键盘焦点状态。按钮保留现有文案、尺寸、位置、条件渲染与点击处理。

不修改协作者权限、治理模式授权、接口、持久化或翻译资源。

## 验收

- 浅色和深色主题中均能一眼读出“治理模式”或“普通模式”。
- 鼠标悬停和键盘聚焦状态可见。
- 现有切换与关闭按钮的布局和操作不受影响。
