# 智能画布单 LoadImage 局部遮罩设计

## 目标

让智能画布的“局部编辑 → 遮罩”产物可用于只有一个 `LoadImage` 节点的 ComfyUI API 工作流。该节点继续同时输出 `IMAGE` 与 `MASK`；工作流本身不需要增加第二个 `LoadImage`。

## 用户体验

1. 用户在原图节点打开局部编辑并绘制遮罩。
2. 点击“保存遮罩”后，原图保留；画布右侧创建独立遮罩节点。
3. 遮罩节点的缩略图显示原图，并在绘制区域覆盖半透明粉色色块和“遮罩”标识；不显示透明镂空预览。
4. 用户将原图节点和该遮罩节点连接至目标 ComfyUI 生成节点。
5. 运行时，画布将这对素材合成为临时 RGBA PNG：原图保留 RGB，绘制区域按 ComfyUI `LoadImage` 的遮罩语义写入 Alpha。该临时文件传给工作流中唯一的 `LoadImage.image`。

## 配对与数据流

- 保存遮罩时持久化其来源原图标识，形成明确的原图—遮罩关系。
- 第一版仅支持一个普通图片输入与其关联的一个局部编辑遮罩；多原图、多遮罩或任意上传图充当遮罩不在本次范围内。
- 工作流配置新增一等 `type: "mask"` 字段。该字段以 `for` 指向它附属的 `type: "image"` 字段，而非直接覆盖一个 ComfyUI 文件输入。例如：

  ```json
  {
    "id": "source", "type": "image", "node": "240", "input": "image"
  }
  {
    "id": "source_mask", "type": "mask", "for": "source"
  }
  ```

  `source_mask` 表示“传给 `source` 的局部编辑遮罩”。运行时由画布合成 RGBA PNG，再将该 PNG 写入 `240.image`；一个 `LoadImage` 因此同时输出原图 `IMAGE` 和该遮罩对应的 `MASK`。
- `mask` 字段是稳定的可映射参数：工作流当前是否接出或消费 `MASK` 端口不影响配置声明、画布连线或遮罩保存。未配置/未连接遮罩时，`source` 保持普通图片传输。
- 运行前从连线输入中找到普通图片和与之匹配的遮罩，上传/生成 ComfyUI 可读的合成 PNG 名称，再写入关联的 image 字段。
- 没有遮罩时保持现有图片工作流路径，不改变原有行为。

## 错误处理

- 遮罩来源图片缺失、尺寸无法读取或无法合成时，阻止本次运行并提示可恢复错误；不得悄悄传入错误遮罩或另一张图片。
- 遮罩未连接时不自动寻找画布中其他遮罩。
- 不改变既有 ComfyUI 后端选择、媒体同步、任务轮询和结果下载链路。

## 验证

- 单元/定向验证：遮罩 PNG 的 Alpha 合成方向、原图与遮罩配对、无遮罩回归路径。
- 前端验证：保存遮罩后原图仍存在；遮罩节点正确显示原图与半透明覆盖；运行参数指向合成的 PNG。
- 执行验证：使用一个 `LoadImage` 且其 `IMAGE`、`MASK` 分别接后续节点的 API 工作流，确认两路输出符合遮罩绘制范围。
- 基础检查：`node --check static/js/smart-canvas.js`、相关智能画布测试与 `git diff --check`。
