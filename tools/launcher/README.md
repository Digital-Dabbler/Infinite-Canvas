# 可视化启动器

双击项目根目录的 `启动器.bat`，会弹出一个独立的「启动器」窗口。

- 服务：窗口里点【启动 / 停止 / 重启】，不用再去双击 `启动服务.bat`、也不用常开终端；第一次打开时若服务没在跑会自动启动。
- 更新：【检查更新】看 GitHub 上你的仓库比本机多了什么，【一键更新】合并进来；冲突时逐文件选「保留我的 / 用新版」，也可批量一键选边；随时可【撤销更新】回到更新前。【备份我的改动到 GitHub】= 推送当前分支。
- 日志：窗口底部实时滚动服务输出；关窗口不影响服务运行，启动器自身在窗口关闭约 2 分钟后自动退出。

安全边界：只监听 `127.0.0.1`（局域网同事访问不到）；停止服务只杀本项目 `python\` 目录启动的进程，不会误伤 ComfyUI 等其它 Python 程序。

实现文件：`tools\launcher\launcher.py`（标准库后端）+ `tools\launcher\launcher.html`（界面）+ `启动器.bat`（入口）。测试见 `tests\test_service_launcher.py`。
